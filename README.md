# Nithin ModMenu AI Training Lab

Native Android Studio training application for a controlled local scene. It demonstrates cheat-related feature concepts for chatbot detection without attaching to or modifying another app.

## Build APK
Open this repository in Android Studio, or use GitHub Actions:
1. Open the Actions tab.
2. Select "Build Android Debug APK".
3. Select "Run workflow".
4. Download the artifact named "Nithin-ModMenu-AI-Training-Lab-debug".

No signing credentials are required for a debug APK.

## Included
- Landscape Android activity and draggable in-app panel.
- Local moving target scene and visual opaque wall.
- Toggleable player-box ESP and occluded dummy-target visualization.
- FOV and smoothing controls for a visual target-selection test.
- Crosshair, HUD and JSON training-event export.
- Labelled chatbot detection dataset.

This project does not request overlay permission, access other apps, hook processes, modify game memory, automate live-game aiming, or bypass anti-cheat.
